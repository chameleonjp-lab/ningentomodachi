# Android 42モーション・1.5倍速版

等速版 completed42 を残した別バージョンです。移動9・ジャンプ1・パンチ13・蹴り19の計42件を重複なく収録しています。各カテゴリのGLB、manifest、index、検証記録、チェックサムのみを収録し、元画像・動画・BLEND・色違いモデルは含めません。

## 再生方法

GLBの時間軸はすでに1.5倍速化済みです。ランタイムの timeScale / speed は1.0で使用してください。さらに1.5を掛けると元の2.25倍速になります。

動作・ポーズ・移動距離・モデル・材質・リグを維持し、再生時間のみ元の2/3へ変更しています。共有入力アクセサは一度だけ変換してfloat32に丸め、アニメーション出力とその他のバイナリを保持しています。JSONの変更は入力アクセサのmin/maxのみです。AcrobaticComboの半フレームを含む311時刻も保持しています。

各GLBはモデル付きです。複数カテゴリを読み込む際はモデルの多重表示に注意してください。元データの未参照アクセサとBIN領域も保持しており、容量削減版ではありません。

## マニフェスト

fpsは45、original_source_fpsは30です。元フレーム番号を保持し、イベント秒は (frame - source_frame_range[0]) / 45 で求めます。秒単位の時刻・継続時間は2/3倍、秒単位の速度は1.5倍です。フレーム単位の変位・誤差は変更していません。継承した等速時の説明文は元資料の注釈として明示されています。実行時の数値は更新済みフィールドを参照してください。

## 検証と制限

verification.json は4カテゴリGLBの元データとの比較記録です。42件の分類、時間変換、出力・静的データ保持を独立検証済みです。SHA256SUMS.txt で同梱ファイルを照合できます。

ルート移動は一度だけ適用し、移動・旋回した終端を原点へリセットしないでください。実機の操作感・接地・衝突・コントローラー・ゲームプレイの受入検証は含みません。
