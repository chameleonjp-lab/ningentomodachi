# Android 42モーション・カテゴリ別

移動 9 / ジャンプ 1 / パンチ 13 / 蹴り 19。各モーションの主カテゴリは1つのみで、全42件を重複なく収録しています。

- movement/android_movement.glb: 待機・歩行・走行・ステップ・方向転換・しゃがみ移動。
- jump/android_jump.glb: 攻撃を伴わない Jump。
- punch/android_punch.glb: パンチ、掌打、肘打、空中の手技攻撃。
- kick/android_kick.glb: 蹴り、払い、膝撃、空中の脚技攻撃。

## 分類ルール

空中にいることだけを理由にジャンプには分類しません。SpinningAttack は蹴り、FlippingSlash と DivingLunge はパンチです。膝撃は蹴りに含めます。AcrobaticCombo は蹴り1発と手技3発の混合連撃なので、主カテゴリはパンチ、副タグは kick / mixed_attack / aerial / acrobatic / combo としました。KungFuAcrobaticCombo は脚技3発のため蹴りです。

index.json で全クリップと主カテゴリ、副タグ、GLBのパスを参照できます。各カテゴリの manifest.json には元データのタイミング・接地・ルート移動・攻撃イベントを保持しています。元画像とプレビュー動画は同梱しないため、それらへのファイル参照は除外しています。

## データ保持と検証

元の42件統合GLBは変更していません。カテゴリGLBは animations 配列のみを抽出し、その他のglTF JSON値、モデル、スキン、マテリアル、全BINチャンクを保持しています。キーフレームの再サンプリング・座標変換・再エクスポートはしていません。

各GLBは単体読み込み可能なモデル付きファイルです。完全なバイト保持を優先し、他カテゴリ由来の未参照アクセサ/BIN領域も意図的に残しています。公開される animations 配列にはそのカテゴリのクリップのみを含みます。容量削減版ではありません。複数ファイルを読み込む際はモデルの多重表示に注意してください。

verification.json に、42件の過不足・重複検査、静的JSONとBINの一致、各チャンネルの入力/出力アクセサの元バイト一致とSHA-256を記録しています。SHA256SUMS.txt は同梱ファイルのチェックサムです。

## 実行時の注意

これはアニメーション資産です。実機アプリへの組み込み・操作感・ゲームプレイ・当たり判定の検証は含みません。移動/旋回する終端を原点へリセットせず、ルートモーションは適用または抽出のどちらか一度だけ行ってください。詳細は各manifestの runtime_boundary、root_motion、start_end_use を参照してください。

BLEND、元画像、プレビュー動画は同梱していません。
